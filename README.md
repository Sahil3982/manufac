# Geriatric Care Assessment Form

## Overview

This project implements a one-page geriatric care assessment form for a visiting nurse. It uses a Zod schema as the single source of truth for validation and a Mantine form for the user experience.

## Tech stack

- React 19
- TypeScript
- Vite
- Mantine
- Zod 4
- Vitest
- React Testing Library

## Install

```bash
npm install
```

## Run locally

```bash
npm run dev
```

## Run tests

```bash
npm test
```

## Build for production

